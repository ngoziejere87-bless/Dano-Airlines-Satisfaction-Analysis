# Dano Airlines Passenger Satisfaction Analysis

## Project Overview
This project analyzes passenger satisfaction data for Dano Airlines, a UK-based airline headquartered in London. The objective is to understand satisfaction levels, identify areas for improvement, and recommend data-driven strategies to enhance the passenger experience.

## Business Problem
Dano Airlines' passenger satisfaction rate has fallen below 50%. The airline needs insights into customer types, travel classes, flight delays, and service ratings to guide improvement efforts.

## Project Objectives
- Measure overall passenger satisfaction.
- Compare first-time and returning passengers.
- Examine satisfaction across travel classes.
- Analyze selected passenger service ratings.
- Recommend strategies to improve passenger experience.

## Tools Used
- Microsoft Power BI Desktop
- Power Query
- GitHub

## Dataset
The dataset contains more than 120,000 passenger survey records, including customer information, travel class, arrival delays, service ratings, and satisfaction.

## Key Performance Indicators
- **Total customers:** Approximately 129.88K
- **Average customer age:** 39.43 years
- **Average arrival delay:** 15.09 minutes
- **Overall customer satisfaction:** 43%

## Key Findings

### Overall Satisfaction
The dashboard reports an overall satisfaction rate of 43%, below the 50% threshold highlighted in the business problem.

### Customer Type
First-time passengers had a satisfaction rate of approximately 23.97%, compared with 47.81% for returning passengers. This difference suggests that the first-time passenger experience deserves further investigation.

### Travel Class
Business Class recorded the strongest satisfaction performance, while Economy Class had the lowest satisfaction rate among the classes examined.

### Service Ratings
The analysis compared seat comfort, cleanliness, baggage handling, in-flight Wi-Fi, food and drink, and arrival delays. These comparisons highlighted potential areas for improvement, particularly within the Economy Class experience.

These findings identify areas for further investigation and do not, by themselves, prove that any single factor caused low satisfaction.

## Recommendations
1. Investigate Economy Class passenger feedback on seat comfort, cleanliness, and food and drink.
2. Review in-flight Wi-Fi reliability and monitor passenger ratings.
3. Improve guidance and support for first-time passengers throughout their journey.
4. Investigate arrival delays and monitor their relationship with satisfaction.
5. Review baggage-handling complaints and performance.
6. Track satisfaction and service ratings over time to measure the impact of improvements.

## Conclusion
The analysis indicates that passenger satisfaction is 43%, highlighting the need for targeted improvement. Dano Airlines should investigate the Economy Class experience, first-time passenger needs, and selected service areas. Proposed changes should be tested and evaluated using passenger feedback and ongoing performance measurements.

## Project Deliverable
The main deliverable is a single-page Power BI dashboard presenting satisfaction KPIs, customer-type comparisons, travel-class comparisons, service ratings, and recommendations.
